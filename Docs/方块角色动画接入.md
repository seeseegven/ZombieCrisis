# 方块角色动画接入

适用：BP_ZC_Player、BP_ZC_BlockZombie。使用现有 StaticMesh 方块组件制作程序动画，不需要骨骼或动画蓝图。

## 已提供接口
- SetAnimationSpeed(Speed)：传入水平移动速度（cm/s），驱动行走摆动；传 0 平滑停止。输入限制为 0–900。
- ResetZCAnimation()：立即恢复初始站立姿势，清空速度及动画状态。
- PlayAttackAnimation()：仅僵尸，播放一次抬臂、前挥、收回动画，约 0.75 秒；播放中再次调用会被忽略。
- IsAttackAnimationPlaying：僵尸攻击动画状态，可供外部逻辑查询。

AnimationSpeed 默认为 0，不会在静止时自动原地踏步。
玩家参考步速 300 cm/s、步频 1.8 Hz、腿部最大摆角 30°；僵尸参考步速 150 cm/s、步频 1.15 Hz、腿部最大摆角 22°。
玩家手臂与腿反向摆动；僵尸保留前伸双臂，行走时轻摆，攻击时由攻击姿势接管双臂，腿部仍可行走。

## 你接移动控制时
在自己的移动逻辑中取得实际水平速度，并调用 SetAnimationSpeed。
CharacterMovement 可使用 Get Velocity → Vector Length XY → SetAnimationSpeed。
如果通过 SetActorLocation 等方式移动而没有更新 Velocity，请自己用水平位移 / DeltaSeconds 计算速度后传入。
停下、被墙阻挡或停止移动时传 0；动画不会推动角色移动。
Event Tick 已连接 UpdateZCAnimation(DeltaSeconds)，请保留这条调用。新增移动逻辑时可以使用 Sequence，避免覆盖或重复调用动画更新。
UpdateZCAnimation 为内部逐帧更新函数；正常接入仅设置速度，不用每帧再调用它。

## 攻击范围
动画只表现动作，没有攻击输入、AI、伤害检测、命中事件或冷却机制。
后续攻击逻辑自行决定何时调用 PlayAttackAnimation、何时结算伤害。
面朝方向沿现有角色本地 +X。手脚绕肩部/髋部计算姿势，不改变角色根节点位置及缩放。

## 验证脚本
Scripts/Editor/check_block_character_animations.py 在 PIE 中检查行走左右摆动、停止恢复、攻击阶段、重复触发和根节点位置不变。
Scripts/Editor/build_block_character_animations.py 是编辑器构建工具；后续你添加移动逻辑后，不要随意重跑它，以免重建事件图。游戏运行不依赖 Python。
